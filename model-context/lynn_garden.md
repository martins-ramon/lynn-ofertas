# LYNN Garden
 
* **URL de acesso:** [https://garden.totvs.io/](https://garden.totvs.io/)
* **Login:** integrado com o google
 
## Histórico
O Garden nasceu de uma iniciativa da área de Governança (head Ronie Teixeira), estimulado pelo Cris Nóbrega, com o objetivo de entregar agentes de eficiência operacional para áreas internas da TOTVS. Como o LYNN ainda está em desenvolvimento e com principal foco na integração com o ecossistema da TOTVS (identity, MCP Server desenvolvimento pelo time de Framework, uso de smartlink, etc), o Garden acabou sendo foi construído como um projeto independente, conduzido pelo Alestan (coordenador do time do Ronie). Atualmente, ainda é um protótipo sendo validado de forma controlada (embora já possua por volta de 500 usuários internos).
 
## Arquitetura
Uso do OpenAI Agents SDK. Atualmente, está utilizando o LYNN Proxy para controle de acesso aos modelos de IA.
 
## Desafio
O LYNN Garden foi apresentado ao grupo de diretores da TOTVS em agosto/26 e, no final do mesmo mês, ao conselho de administração da TOTVS. Possui um alto grau de aceitação. Porém, o fato dele ter sido apartado transmite uma mensagem ruim para a TOTVS. Inclusive, este é um fato que não tem recebido publicidade. O discurso oficial é que ele foi desenvolvido sobre o foundation LYNN, mas isto não é realidade. Precisamos criar uma estratégia de convergência, lembrando que o foundation LYNN possui como principais pilares (Builder, Enterprise Layer e Governance).
